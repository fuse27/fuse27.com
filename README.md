# fuse27.com

Static site for Fuse27, hosted on GitHub Pages.

- `/` studio home
- `/twotop/` TwoTop page and support (App Store "Support URL")
- `/twotop/privacy/` TwoTop privacy policy (App Store "Privacy Policy URL")

Preview locally: `python3 -m http.server 8427` in this folder, then open http://localhost:8427
